# 4 Semesters From Now · CUD Entrepreneurship Pathway

Proposal site by Eng. Nadia Mek (Canadian University Dubai).

- `index.html`: the 4-semester ENT pathway (ENT 141 → 142 → 241 → 242), linked to CUD research and the CUD Incubator
- `ent141.html`, `ent142.html`: part-by-part syllabus reviews of the GED courses (current vs proposed)
- `ent241.html`, `ent242.html`: part-by-part syllabus reviews of the Business courses, built on the committee's weekly activities (30/10/2026)
- `ent141-syllabus.html` to `ent242-syllabus.html` and `files/`: the suggested syllabi in the CUD template (page, Word, PDF)
- `ent141-new.html`, `ent142-new.html`: course demos (course home, class demo, studio/lab demo)
- `studio.html`: Syllabus Review Studio (password-protected tool: upload a current syllabus, review each part, export the new syllabus)
- `incubator.html`: incubator demo (Solve It board, inspired by Soolvit; 4SFN Day, inspired by 4YFN Barcelona)

Partners and teams in the demos are fictional.

How a pilot review works
  1. Open the pilot copy. A review box sits on the right of every page.
  2. On each page, speak or type what should change. Use “Point to a part” to attach a comment to one box, graph or example.
  3. Mark pages with no changes as “Looks good”. “All pages” shows what is left.
  4. Press “Send my review”, save the file and email it to the course builder team.

Comments stay on your own device until you send them. Use the same browser for the whole review.
